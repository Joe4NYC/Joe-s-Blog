申請實習的季節，最煩的是要每天打開十幾個 career page 看有沒有新職位；讀書的時候，最怕的是有老師只把測驗日期寫在 PDF 講義裡，Canvas 的行事曆完全沒有。兩件事本質一樣：**有一堆網頁要定時看，看漏一次就可能錯過**。

所以我在 Oracle Cloud 開了一部免費 VM，讓它替我看。這篇講兩個跑在上面的小工具——jobwatch 和 canvaswatch——為什麼這樣設計，以及開 VM 時要注意的地方。

<!-- more -->

## 為什麼是一部雲端 VM

我本來在家裡的 router（NanoPi R3S）上已經跑 Docker 自架小服務，但定時抓網頁這類工作，我想放在一部長開、不受家裡網絡影響的機器上。最後選了 Oracle Cloud：

| 項目 | 選擇 |
| --- | --- |
| 雲端 | Oracle Cloud，Always Free 範圍內 |
| 機房 | 新加坡（離香港近） |
| 帳戶 | 升級成 Pay As You Go，才搶得到 A1（ARM）規格 |
| 保險 | 設定預算提醒，超出免費額度就通知我 |
| 部署 | 用 Claude Code 幫手寫程式和部署 |

升級成 Pay As You Go 聽起來有點嚇人，但這是為了拿到 A1 的機器容量；配合預算提醒，實際上仍然留在免費範圍內。

## jobwatch：有新實習職位就推去 Telegram

jobwatch 監察幾類機構的實習招聘頁：本地和亞洲的銀行、外資投行，以及金融監管機構。它定時把職位列表抓下來，跟上次的結果比對，有新職位就經 Telegram bot 推到我手機。

這樣我不用每天逐個網站刷，只需要看 Telegram。

## canvaswatch：把藏在 PDF 裡的死線抓出來

Canvas 本身有行事曆，也可以匯出 .ics 訂閱。問題是**有些老師不在 Canvas 設定日期，只把死線寫在 PDF 或課程頁面的文字裡**，.ics 自然就漏了。

canvaswatch 做的事是：掃我每一科的 Canvas 內容，包括頁面和 PDF，從文字裡找出日期，再直接推上儀表板。設計上我定了幾個決定：

| 決定 | 選擇 | 原因 |
| --- | --- | --- |
| 結果放哪裡 | 直接推上儀表板 | 我每天本來就看儀表板，不想多一個地方 |
| 頻率 | 每天兩次，早上 8 點、晚上 8 點 | 死線不會一小時內冒出來，一日兩次足夠 |
| 程式放哪 | 獨立一個專案，不塞進 jobwatch | 兩個工具目的不同，分開比較好維護 |
